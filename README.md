## Overview
This application extends our Week 10 OOP Transit System by incorporating asynchronous Dart features:
- **Future-returning Methods:** `processTripPaymentAsync()` and `trackLocation()`.
- **Future.delayed:** Simulates realistic network/server delays (2 seconds).
- **async / await:** Used in `main()` and methods to handle non-blocking execution safely.

## How to Run
1. Open [DartPad](https://dartpad.dev).
2. Copy and paste `bin/async_exercises.dart`.
3. Click **Run**.
